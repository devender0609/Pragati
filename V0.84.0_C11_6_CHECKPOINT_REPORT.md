## O/P. Representation risk — 56 C, 30 B, 7 A

**Chapters 1, 2, 4, 6, 10 and 12 are C throughout.** Sets, functions as
objects, complex arithmetic, counting, conics, limits and derivatives — six
frontiers with no model that can represent them.

**Chapter 3 is C for a specific reason**, not because trigonometry is hard:
`specialAngles` is degree-based and acute-bound. Radians, the unit circle,
quadrant signs and functions over ℝ each break that assumption directly.

A is only 7 units — statistics dispersion, which `groupedDistribution`
genuinely owns, and one-variable inequalities. B is mostly extension work:
3-D coordinates, probability event algebra, G.P., line forms.

## Y. First authoring pilot — Chapter 1, Sets

Not executed. Chapter 3 trigonometry is the loudest risk, but Sets is the
better first pilot.

Sets is **12 units, all C, and every one of them needs the same missing
thing**: a model that represents a collection as an object with membership,
containment, the operations and a Venn rendering. Nothing else in Class 11
depends on getting trigonometry right first, whereas **Chapter 2 functions,
Chapter 14 probability's event algebra and parts of Chapter 10 all sit on set
semantics.** Building that model first pays three times.

Trigonometry should be the *second* pilot, and it needs its own decision
rather than an extension: `specialAngles` should probably be left alone and a
radian-based function model built beside it, since Class 10's 65 frozen
lessons depend on the existing one behaving exactly as it does.
