## 11. Evidence hierarchy policy

`docs/CURRICULUM_EVIDENCE_POLICY.md` plus `evidenceHierarchy.ts`.

**Authority is per claim type, not universal** — the core insight:

| Claim | Strongest source |
| :--- | :--- |
| Curricular structure | National framework |
| Chapter placement | **Current textbook** — the textbook *is* the chapter list |
| Assessment design | National assessment framework |
| Progression order | **Mathematical inference** — dependency is a mathematical fact |

Framework generations (NCF 2005 vs NCF-SE 2023) are tracked, and
`resolveConflict()` **flags a generation mismatch rather than resolving
it silently** — a newer framework may have deliberately changed what an
older document says, which is not the same as disagreement.
