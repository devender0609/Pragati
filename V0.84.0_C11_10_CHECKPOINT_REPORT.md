## C/D/E. Architecture — verdict **B**

`relationsFunctions.ts` is built on checkpoint 79's `setTheory` with **no
second set implementation**. Domains, codomains and ranges are `ExplicitSet`
objects, not strings, which is the payoff that module was built for.

It deliberately **does not absorb `circularFunctions`**. Those six functions
carry exact trigonometric semantics — exact values, periods, branch-safe
graphs — and flattening them into a generic callable would lose all of it.
Instead a small `RealFunctionContract` is declared here, and a compatibility
test shows `tan` satisfies it while keeping its own period and domain
machinery untouched. The contract is satisfied by the trigonometric model,
not imposed on it.

## F. Cartesian product

`(1,2)` and `(2,1)` are different; `A \u00d7 B` and `B \u00d7 A` are different **despite
equal cardinality**, and that trap is a worked example rather than a footnote.
The product is derived from the factors, so a duplicated roster entry creates
no extra pair. Triples work without n-ary machinery: `R \u00d7 R \u00d7 R` is the same
construction, and a two-element set gives 8 triples.

## G. Relations

Domain and range are **derived from the pairs**; the codomain is the
**declared** target. The canonical relation has range `{p}` inside codomain
`{p, q, r}`, and a test asserts the two are not equal — an implementation
equating them fails there. A pair with a coordinate outside either set is
rejected with a message naming which coordinate.

## H. Function validity

Both failures are caught separately: an unmapped input, and an input with two
images. **Many-to-one is accepted.** A relation missing an input is not
silently rescued by shrinking its domain — it is simply not a function from A.

## I/J. Standard real functions and their graphs

Nine families with domain, range, rule and evaluation as properties of the
function. The logarithm excludes non-positive arguments structurally; the
reciprocal excludes zero. **No value is ever Infinity or NaN** — a test sweeps
every function across a range and checks.

Graphs come from the rules. Signum draws in 3 pieces and the greatest-integer
function in 7, because those functions **jump**; the reciprocal draws in 2
branches because it has **no value** at zero. Those are different situations
and the Think deeper question is about exactly that distinction. A
deliberately joined graph is rejected.

## K/L. Algebra of functions

Sum, difference and product take the intersection of the domains. A quotient
additionally removes every zero of the divisor, and **that restriction lives
in `inDomain`**, so simplifying the written rule cannot discard it. The lesson
makes the point directly: two formulas that agree wherever both are defined
are still different functions if their domains differ.
