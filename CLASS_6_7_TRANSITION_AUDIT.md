# Class 6 to Class 7 — interim transition audit

Written from the complete Class 6 decomposition and the **four Class 7 chapters
decomposed so far** — Large Numbers Around Us, Arithmetic Expressions, A Peek
Beyond the Point, and Expressions Using Letter-Numbers. **[S]** source
observation, **[P]** Pragati recommendation. Eleven Class 7 chapters are not
yet read, so this audit is deliberately partial.

## Number

**[S]** Class 6 reaches lakhs through place value; Class 7 opens at a lakh and
goes to crores, arabs, and the Indian **and** American naming systems for one
number. Rounding becomes a choice of place rather than an instruction.
**[S]** No prerequisite gap: every Class 7 number unit rests on Class 6 place
value.

## Expressions — the real jump

**[S]** This is the sharpest change at the boundary. Classes 1-6 *compute*
values. Class 7 makes the **expression itself the object of study**: terms are
named, subtraction is rewritten as adding a negative, terms are swapped and
grouped with the Class 6 token model supplying the justification, brackets are
removed under a stated rule, and the distributive property is used as a tool.
**[P]** Author §2.1 and §2.2 in that order and keep the token model visible;
it is the only bridge back to Class 6 that the chapter offers.

## Decimals

**[S]** Class 6 establishes the fractional unit and fraction arithmetic. Class 7
subdivides the unit into tenths, then hundredths, then thousandths, and only
then names the decimal point — decimals arrive as an **extension of place
value**, not as new notation to memorise.
**[S]** One dependency worth noting: §3.2 onwards assumes the Class 6
fractional-unit work (ch 7 u3) fluently. That unit currently has an authored
lesson, so the bridge exists.

## Algebra

**[S]** Letter-numbers are entirely new. Class 6 generalises patterns in words
and pictures; Class 7 writes 4n for the nth multiple of 4, collects like terms,
removes brackets in algebra and tests whether two expressions are equal by
substitution.
**[P]** The chapter rests on the expression work of chapter 2 — author them as
one sequence, not as separate strands.
