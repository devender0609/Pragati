## What this release completes

v0.72 declined to build the authoring pipeline (§16–§21), arguing that a
generator built before an educator approves the format would mass-produce an
unapproved shape.

**That argument holds for content. It does not hold for planning.** The
distinction is the whole design of this release: `contentPlan.ts` authors
nothing. It produces a work plan — for each official record, what is missing,
what shape the missing thing should take, and in what order the work is worth
doing. Every input is already-derived data.

`assertNoContentGenerated()` is a standing test that it never starts: if a
future change makes the planner emit prose, item stems or answers, it names the
offending field and the suite fails.

## §17 — the target shape comes from the audited chapter

A plan needs to know what a section should look like. That shape is **derived
from Chapter 7 as it actually is** — the only shape Pragati has taken through
three hand audits, a pedagogy audit and review preparation.

Reported as the **median**, so one unusually long section cannot raise the bar
for every future one and §7.9 (deliberately light) cannot lower it. The plan
target is the *maximum* of that median and the completeness gate's minimum, so
a plan never aims below either.

Inventing a richer ideal would mean planning against a shape nobody has
produced, let alone reviewed.

## Applicability is respected in planning too

§7.9 generates **no** work item for a visual or an interactive item, because
those requirements are waived with reasons. Planning them would mean bolting a
quiz about dates onto a discussion section — the same failure mode the
completeness model was built to avoid, one layer up.

A test asserts this directly.

  guided item, one independent item) are small and should still wait for
  review, since a reviewer may have a view on what that section needs.

  generator have been ready since v0.70; it needs a person and a textbook.
- **Teacher screens beyond Overview** still have the palette and the nav change
  only, and remain centred mobile at 1440. §18's Teacher/Admin differentiation
  is real but one-sided: Admin gained an identity, Teacher did not.
- **No draft-generation workflow.** The plan says what to write; nothing writes
  it. That remains correct until the format is approved.
