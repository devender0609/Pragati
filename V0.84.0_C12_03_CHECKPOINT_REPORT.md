### The mistake worth naming

Checkpoints 108, 109 and 110 all dismissed this file as a Secondary-stage
Class IX–X syllabus, on the strength of `SecP2` in the filename and a
12-page length. `SecP2` means **Senior Secondary Part 2**.

I judged a source by its filename — the precise failure this project
forbids for editions, and I did it three times while insisting on primary
evidence elsewhere. The file was sitting in uploads the whole time.
