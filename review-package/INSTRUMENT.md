# The Class 9 review instrument, version 1

## Why it is not 37 questions

Thirty-seven questions across 92 lessons is 3,404 answers per reviewer. Nobody
reviews carefully at that length; the form gets filled rather than considered.

So the instrument is **10 core questions** every lesson is judged on, plus up
to 6 that apply only when the lesson has the feature in question. In practice
12 to 15 per lesson, 1,195 across all 92 for one perspective.

## Core — every lesson

**Mathematics**
- M1 Is every mathematical statement correct?
- M2 Does each worked example's reasoning justify its step, rather than restate it?
- M3 Are the answers and the feedback given to students mathematically right?

**Source fidelity**
- S1 Does it stay inside what the source section teaches?
- S2 Is the terminology the one this textbook uses at this stage?
- S3 Does it meet the source's mathematical intent, rather than a thinner version?

**Instruction**
- I1 Would a Class 9 student following this understand the idea?
- I2 Does it build on what comes before and prepare what comes after?
- I3 Is the practice worth doing — does it test the idea, not the arithmetic alone?
- I4 Does Think deeper ask for reasoning a strong student could not answer by recall?

## Applied only when the lesson has the feature

| Question | Asked when |
|---|---|
| V1 figures show the mathematics correctly | the lesson contains figures |
| V2 figures readable on a phone | the lesson contains figures |
| D1 charts faithful, table agrees | the lesson contains data displays |
| S4 integration of multiple source sections is faithful | the lesson carries additional provenance |
| S5 represents unnumbered source pages without implying structure | the lesson is segment-backed |
| T1 teacher notes accurate and useful | the lesson carries teacher notes |
| X1 feedback names the mistake rather than marking it wrong | the lesson gives guided-practice feedback |

V1, V2 and D1 are **presentation-dependent**: they are about what was
rendered, so they are invalidated when the review build changes, while the
rest survive it.
