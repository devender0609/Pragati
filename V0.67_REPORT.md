## 10. Did the manual audit find errors?

**Yes — two, both fixed.**

1. **§7.7 distractor mis-tagged.** "They are equal, because both have 2
   on top" was tagged `counts_ticks_not_spaces`. That is
   compare-numerators-only. The student would have been told something
   untrue about their own error.
2. **§7.8 distractor mis-tagged.** The answer `2/8` was tagged
   `bigger_denominator_bigger_fraction`. It comes from adding the
   denominators — a different mistake.

Both now carry `null` and receive neutral guidance. The correct IDs
exist in the new registry but not in the older enum the interaction
layer uses, and extending that enum would have broken the frozen
fingerprint. A wrong diagnosis is worse than none.

## 15. Recommended chapter-review strategy

**Option A**, with a sequencing condition.

Wait for the §7.4 Package B response before instrumenting anything else.
That review is not only about §7.4 — it tests the authoring template all
eight new drafts follow. If a reviewer rejects the worked-example
structure or the misconception wording, the same objection applies nine
times over, and eight more questionnaires sent now would collect the
same complaint eight times.

Once §7.4 is adjudicated: a **short per-section instrument** (~8–10
questions: mathematical accuracy, source fidelity, sequence, visuals,
practice) rather than 37 per section. 37 × 9 = 333 questions is not a
request any teacher should receive.

Option B (deep review of representatives) risks a systematic error in an
unsampled section. Option A costs more reviewer time but each section
gets looked at.

## What this version does NOT claim

Nine drafts is nine drafts. None has been read by a teacher. The
validators check structure — that a worked example has a rationale, that
a visual's semantics are consistent — and prove nothing about whether
the teaching is any good. The mathematics was audited by hand and two
real errors were found, which is a reason to expect a reviewer will find
more.
