## §1 — the false headline

`CURRICULUM_COVERAGE_MATRIX.md` said:

> 12 complete instructional drafts, all in Class 6 Chapter 7

Wrong since Number Play was authored, and it would have stayed wrong
through every future chapter, because the clause was a literal in the
generator. Nothing computed it and nothing could contradict it.

It now reads **"12 complete instructional drafts — 3 in Number Play, 9
in Fractions"**, derived from the authored registry. A chapter added
later appears without anyone remembering to edit a sentence, and the
test that checks this is registry-driven rather than naming Number Play,
so it fails if a future chapter goes missing.

## §2-§4 — review state, per chapter

The matrix's "Currently: 9 sections are in state 4" read as a product
statement and was the Fractions-only summary. It is now a table by
chapter with an explicit total:

| Chapter | Complete drafts | Review-ready |
|---|---|---|
| Number Play | 3 | 3 |
| Fractions | 9 | 9 |
| **Total** | **12** | **12** |

The document says in words that the packages stay chapter-scoped — the
total is a report, not a queue. `CONTENT_BACKLOG.md` now carries a
**Review state** block for each authored chapter, generated by iterating
the registry rather than by a second hard-coded heading.

## §3 — the deprecated wrapper is out of state generation

`stateDocs.ts` imported `reviewReadinessSummary()`, which is deprecated
and Fractions-only, and used it for product-wide claims. Replaced with
`reviewReadinessByChapter()` and `reviewReadinessSummaryForChapter()`.

## §5 — the metric that looked wrong

`Chapters with Learn = 1` while authored content exists in two chapters.
Audited: it counts chapters with a **student-openable** section, and by
that definition 1 is correct — nothing in Chapter 3 is published, and in
Chapter 7 only the one openable section is.

**The value was right and the column name was misleading.** Renamed to
**"Student-openable Learn chapters"**, with the definition written at
the field. I did not change it to 2: that would have made a true number
false to fix a label.

byte-identical. §7.4 remains frozen. A documentation cleanup must not
