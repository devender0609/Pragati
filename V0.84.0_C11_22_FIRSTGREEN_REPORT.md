The 35 failures were never about state-doc timing. `JSON.stringify` cannot
serialise a `bigint`, and the artifact fingerprint pipeline runs through

took down the whole fingerprint path while the targeted suite stayed green.

The boundary is now explicit and both properties survive:

- **model** — exact `bigint`; 25! is `15511210043330985984000000`
- **artifact payload** — canonical decimal string, no Number, no rounding,
  no scientific notation
- **validator** — recomputes the expected count from the semantic model and
  compares, so the string never becomes a second independent truth

All five Chapter 6 artifacts serialise. A tampered count string is rejected.
