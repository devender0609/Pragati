## The line the validator holds

It checks **structure only**. It rejects a missing reviewer, a stale
fingerprint, an unmapped unit, a missing unit result, a bad enum, a
malformed issue.

**It never rejects a response for what it concludes.** Every Wave 1
artifact passed structural checks and was called READY_FOR_HUMAN_REVIEW —
if a reviewer reads one and returns MISALIGNED, that is the wave working,
not an error to filter. Two tests assert exactly that: `MISALIGNED` plus
`MAJOR_REWORK` plus `SHOULD_SPLIT` is accepted on an artifact the audit
called ready, and a mixed verdict across four units of one artifact is
accepted without being flattened.

Structural readiness was only ever a claim about well-formedness.

## Stale responses

A response whose fingerprint no longer matches gets status
**`STALE_REVIEW_RESPONSE`** and is not applied. The reviewer's reading was
honest; it is simply not about the current text. The new version needs
re-review.

The fingerprint covers instructional content only, so metadata churn
preserves review currency and any wording change does not.
