## What was corrected

**§7.4 educator covering message.** It said "I've built one complete Class 6
fractions lesson … and before I write any more". That stopped being true
once all nine Fractions sections were drafted. It now says:

- there are nine complete Fractions drafts;
- §7.4 goes first as the anchor/template section;
- the reviewer's feedback will guide adjudication of the other eight;
- nothing is published;
- what to judge: age-appropriateness, mathematical clarity, representations,
  practice, and classroom usability.

It also now mentions the student-facing "watch out for" paraphrases by hand,
which the doc already said was required because the frozen §7.4 package
predates them.

**§7.4 curriculum-specialist covering message.** It no longer implies §7.4 is
the only lesson. It still asks only about placement, competency mapping and
prerequisites. The two reviewers stay separate.

**Frozen packages still say "one lesson".** The following files contain that
wording:

- `PACKAGE_B_FOR_REVIEWER.md`
- `PRAGATI_SECTION_7_4_REVIEW_FINAL/README.md`
- `PRAGATI_SECTION_7_4_CURRICULUM_REVIEW/README.md`

They were deliberately NOT edited, because editing them would break the
frozen review identity. Both covering messages explain the wording in one
sentence instead.

**Chapter 3 handoff.**

- The folder is now described as three reviewer markdown files plus
  `index.json`. Only the three markdown files go to the reviewer.
- It now states that the `v1` in a review code (e.g. `S31-v1-20BA61`) is the
  review question-set version (`SECTION_QUESTION_SET_VERSION`), not the
  lesson's `contentArtifactVersion`. Artifact version plus fingerprint
  identify the lesson, and a table lists all three.
