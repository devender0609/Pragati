## G/H. Student validation — where it fails

Navigation is **client state only** — no react-router, the URL stays at the
site root. That is a genuinely useful finding: no SPA rewrite rules are
needed and hard refresh is safe on any static host.

Walking the real production bundle: onboarding completes, the student home
renders, and it offers **Class 6 chapters driven by assessment inventory**.
Class 9's lessons appear nowhere, because the chapter list is built from
item counts rather than from authored Learn artifacts.

So gates 7, 8 and 9 cannot be evidenced. The artifacts are correct and
tested; the route to them does not exist.
