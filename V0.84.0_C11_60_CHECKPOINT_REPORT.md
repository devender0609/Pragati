**Structural coverage: 93 / 93 proven. Material alignment: 0 settled, 93

Coverage answers "is there authored material?". Alignment answers "does it
teach the intended scope correctly?" — a judgement requiring a syllabus
read against prose. A keyword match is not material coverage, so no unit
is reported ALIGNED. Reporting 93 aligned from a generator would have been
the most misleading thing this audit could produce.

### Two defects found — both in my own audit

1. **Eight correctly placed CBSE-only lessons were flagged.** My check used
   `place.startsWith('chapter-')`, and *"chapter-less required"* begins with
   `chapter-`. Corrected to match a numbered chapter.
2. **Five lessons were flagged for raw-value leaks** that were the word
   "undefined" used correctly — *"the function is undefined at x = 2"*. The
   repository's own guard is deliberately narrow; mine was not. Corrected to
   colon-attached values, `NaN`, and `[object Object]`.

Both were caught by reading the flagged artifacts rather than trusting the
count. Had I filed them, this audit would have reported 13 phantom defects
against clean lessons.
