dropped **§2.4, §3.1, §4.4 and §13.4**; all four were found by rendering the
pages. Three threshold settings gave 50, 52 and 70 sections before the corrected
pattern plus visual checks settled it at 74. This is the same defect class that
cost Class 8 its §3.4.

chapter looked like it jumped 4.3 → 4.5 — until PDF page 8 of `iemh104.pdf` was
