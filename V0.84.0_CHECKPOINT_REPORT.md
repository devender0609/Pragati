## The methodological limitation, stated plainly

The first pass used `digest.py`: each page's printed folio, its headings
and its opening ~320 characters. That is an **index**. In Classes 1 and 2
the mathematics usually lives in the ten frame, the bead string, the
number strip, the array, the pictograph or the picture task — none of
which the opening line mentions. Calling 64 units authoring-ready on that
evidence was wrong, and this pass corrects it rather than defending it.

Two concrete proofs that the index was not enough:

- **Class 1 Chapter 13 "Puzzles"** was recorded as rehearsal with no new
  mathematics. Rendering the pages showed a Latin-square constraint task
  (each shape once per row and column), mirror-symmetry number riddles
  and equal-sum crosses — none taught earlier in the book. It is now a
  unit, `pragati_iu_g01_ch13_u2`, flagged for a human decision about
  whether Class 1 enrichment of that kind is in scope.
- **Five chapter tails** the first pass never read contained whole
  objectives: subtraction within 20 and two-step problems (Class 1 Ch 6),
  numbers to 100 (Ch 8), column subtraction with regrouping and fact
  families (Class 2 Ch 6), building tables from tables and division as
  sharing and grouping (Ch 8), clock reading and cardinal directions
  (Ch 9).

The ready count fell by 54 because readiness now means evidence, not
plausibility. `meetsEvidenceBar()` is the single gate: intent INSPECTED,
evidence depth above DIGEST_ONLY, and — where the mathematics is visual —
pages actually rendered and looked at. A test asserts that every unit's
status equals what that function returns, so the data cannot drift from
the rule.

## Canonical status reconciled (§7, §8)

There was one meaning of "page-level intent inspected" in two places.
`MASTER_RECORDS.intentStatus` is now a **live getter** over
`inspectedOfficialRecordIds()` — the decomposition dataset is the record
of who read what, and the master map reads it rather than keeping a copy.
`decompositionCoverage()` no longer collapses three questions into one
number: it reports official records inspected, units with complete
evidence, and classes fully inspected, separately.

## Stale active statements fixed (§9)

today" or that page reading "has not been done except where Pragati has
already authored". A regression test fails if either returns.
