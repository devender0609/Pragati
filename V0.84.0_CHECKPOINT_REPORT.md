**1. Two current status fields.** `hardeningClassification` outlived its pass
and disagreed with `decompositionStatus` on 33 units — Class 3 units reading
READY while still labelled NEEDS_HUMAN_CHECK from the partial visual pass, and
Classes 1-2 units labelled CONFIRMED while genuinely in review. The verdicts
are now **dated `auditHistory`** entries on 165 units; the field and its note are
gone from current state. **Current status contradictions: 0.** Tests forbid
the field returning and assert `decompositionStatus === derivedStatusFor(u)`.

**2. A hard-coded checkpoint-9 sentence.** The Class 3 audit printed
"The class is NOT source-complete…" directly beneath its own
DECOMPOSITION_SOURCE_COMPLETE line. The wording is now derived from
`classProgress[3]`; a test fails if a complete class is described as
incomplete, or the reverse.

**3. Cross-class leakage.** The Class 3 audit listed Classes 1-2 segments and
units because both sections iterated the whole dataset. Both generators filter
by class now. The Class 3 audit lists exactly **59 Class 3 units** and only
Class 3 segments; the Classes 1-2 audit contains no `cemm1` record. Tests
assert both.

**4. "Visual seen" counted the wrong set.** It counted every rendered page
against a visual-required denominator, so rows read 20 seen of 17 required.
Seen now counts pages that were *required and inspected*, with **Pages
rendered** as a separate column. Tests require seen ≤ required on every row,
and equality wherever the record is FULLY_INSPECTED.
