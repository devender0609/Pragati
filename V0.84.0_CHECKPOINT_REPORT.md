## Class 6→7 transition — final

**The integer jump does not repeat.** Class 6's Other Side of Zero had no
Class 1-5 precursor at all; Class 7 Part II **extends it smoothly** — the models
are recapped, then the multiplication sign rules are derived from them by
continuing a pattern. A procedural extension, not a second conceptual jump.

**The one genuine discontinuity is geometric**: parallelism and the transversal
(I.5) have no Class 6 precursor beyond angle measure, and everything deductive
in Class 7 geometry — the angle sum, congruence, the bisector constructions —
rests on them. Sequence I.5 early.

**The algebra sequence is real and spans both parts**: arithmetic expressions
(I.2) → letter-numbers (I.4) → equations solved systematically (II.7).
