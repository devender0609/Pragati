## C/D. Data architecture — verdict **B**

Class 9's `DataSet` holds `categories: string[]`. That is right for
"Household" against "Factory" and **mathematically wrong for intervals**: an
interval's two numbers are needed for the class mark, the class width, and
the median's lower boundary. Storing "20–30" as a name and the class mark as
a separately typed number is exactly how a corrected frequency leaves a stale
mean three columns away.

So `GroupedDistribution` is its own object, general for grouped numerical
distributions, and **nothing derived from it is authored**. It carries an
explicit `convention`, and `boundaries()` splits the gap for inclusive
classes so 20–29 contributes a lower boundary of 19.5 rather than 20.

## G/H/I/J. Cross-method reconciliation — the central invariant

`meansReconcile` tries each class mark as `a` **and deliberately awkward
values** — −1000, −7.25, 0, 3.5, 10000 — because a method that only works for
a convenient choice of `a` is not the method. All three distributions
reconcile at every one, to 9 decimal places.

Recomputed: Σfx = 1020 / 865 / 2100; means 25.5 / 17.3 / 35; Σf·d = 20 and
Σf·u = 2 for the water data at a = 25. A test asserts that **omitting h does
not give the mean** — 25.05 against 25.5 — so the characteristic
step-deviation error cannot pass. Where the widths differ, `classWidth`
returns null, step deviation returns null, and the assumed-mean route still
agrees with the direct one.

## K. Mode fidelity

Modal class by greatest **frequency**; mode computed inside it and asserted
to lie within its boundaries on every dataset. Equal neighbours give the
midpoint exactly. **A tie returns null** rather than silently picking one —
the scope avoids bimodal data, and choosing between two tied classes would
present the solver's choice as a fact about the data.

## L. Median and cumulative frequency

Cumulative frequencies are derived, and tested to rise monotonically, to end
at Σf, and to match a running sum row by row. The median class is the
**first class to reach** N/2 — a test confirms an exact landing counts as
reaching — and the median is asserted to lie inside it.

## M. Rounding policy

Nothing is rounded internally; every statistic is computed in full precision
from the distribution and rounded only for display, to 4 decimal places.
Prose figures are **interpolated from the model**, so they carry the same
precision as the computation behind them. This is what prevents the one
failure mode where two correct methods appear to disagree.
