# Age-Stage Content Authoring Standard

**Written:** 2026-08-24 (v0.61 §13)
Translates `AGE_STAGE_PRODUCT_PRINCIPLES.md` into requirements an author
can be held to. Differentiation that amounts to font size is not
differentiation.

## Classes 1–2 (ages 6–8)

| Dimension | Requirement |
| :-- | :-- |
| Reading load | **Max 6 words per instruction.** Assume the child may not read fluently |
| Explanation length | 1–2 sentences per screen; one concept per screen |
| Notation | Numerals and `+ − =` only. No formal vocabulary |
| Worked examples | 2 steps maximum, each carried by a picture |
| Representations | Concrete objects, ten frames, counting collections |
| Visual density | The visual **is** the content; text supports it |
| Feedback | Immediate, pictorial, never a written explanation |
| Reasoning | "Which is more?" — comparison only |
| Interaction | Tap and drag. Very large targets. No typing |

## Classes 3–5 (ages 8–11)

| Dimension | Requirement |
| :-- | :-- |
| Reading load | Max 15 words per instruction; max 12 words per sentence |
| Explanation length | 3–4 short sentences |
| Notation | `× ÷`, fractions as `a/b`, units. No variables |
| Worked examples | 3–4 steps, **each step annotated with why** |
| Representations | Number lines, area models, bar models, manipulatives |
| Visual density | At least one mathematical visual per concept |
| Feedback | Names the specific error, one sentence |
| Reasoning | "How do you know?" — one-step justification |
| Interaction | Tap, drag, simple numeric entry |

## Classes 6–8 (ages 11–14) — the pilot band

| Dimension | Requirement |
| :-- | :-- |
| Reading load | **Max 25 words per stem.** The current `fractions` bank reaches 53 and must be revised |
| Explanation length | 4–6 sentences, broken by a visual |
| Notation | Variables, exponents, ratio notation, decimals — **introduced in the order the current textbook introduces them** |
| Worked examples | 3–5 steps with explicit reasoning per step; at least one non-obvious case |
| Representations | **At least two** per concept (e.g. length and area for fractions) |
| Visual density | Concept-specific visuals from the typed catalogue. Decorative art does not count |
| Feedback | Addresses the specific misconception, documented at authoring time |
| Reasoning | Multi-step justification; "is this correct, and how do you know?" |
| Interaction | Selection, entry, and **manipulable visuals** (marking a number line) |

Stage-specific rule: competency citations must use **Middle Stage**
IDs (`MIDDLE:C-1.4`). Secondary Stage numbers resolve to different goals.

## Classes 9–12 (ages 14–18)

| Dimension | Requirement |
| :-- | :-- |
| Reading load | Max 40 words; exam-style phrasing is appropriate |
| Explanation length | Full development with formal definitions |
| Notation | Precise and complete — set notation, function notation, proof |
| Worked examples | Multi-step, showing method **selection**, not just execution |
| Representations | Graphs, coordinate geometry, algebraic and geometric forms of one idea |
| Visual density | Accurate graphs and constructions; correctness over decoration |
| Feedback | Diagnostic, including where a method choice went wrong |
| Reasoning | Proof, generalisation, modelling |
| Interaction | Multi-part entry, graph interaction, working shown |

Stage-specific rule: **Secondary Stage** competency IDs
(`SECONDARY:C-6.1`) — a different goal set with eleven goals.

## Cross-stage rules

1. Reading load is part of the mathematics. A child who cannot decode
   the sentence has been given a reading problem.
2. Every visual carries mathematical meaning or is removed.
3. Misconceptions are documented **before** items are written.
4. No stage uses generated text as final content.
