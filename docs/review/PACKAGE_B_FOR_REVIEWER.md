## How to open it

Use the copy of Pragati sent with this pack (`pragati-v0.66.0.zip`).
It is a fixed copy — it cannot change while you are reviewing it.

1. Unzip it, then run `npm ci`, `npm run build`, `npm run preview`.
2. Open the address it prints.
3. Switch to **Teacher mode** (top right).
4. Choose **Admin & Research**.
5. Choose **Curriculum coverage**.
6. Choose **"Open the Section 7.4 reviewer preview"**.

You will see exactly what a student would see, plus teacher notes below.

fraction, choose a strip. They work.
