# Early Primary (Classes 1–2) Growth Assessment — Feasibility

**Status: analysis only. No Class 1–2 test is implemented.**

v0.53 said Classes 1–2 were "out of scope for Growth regardless — the
format assumes fluent reading." **That reasoning was wrong**: it let a
current interface limitation decide an assessment-population question.
The interface is ours to change. This document reconsiders it properly.

---

## 1. What the construct would be

Foundational numeracy — number sense, counting, cardinality, simple
addition and subtraction, comparison, basic shape and space, simple
measurement, and pattern recognition.

**Crucially, this is a real assessment target in India**, not a
hypothetical. PARAKH Rashtriya Sarvekshan assesses foundational-stage
competencies at Grade 3, and NCERT has published Learning Outcomes for
Classes I to VIII including Mathematics. Foundational numeracy is
already treated as measurable by the national system.

---

## 2. Administration models considered

| Model | Reading load | Burden | Verdict |
| :--- | :--- | :--- | :--- |
| Text on screen | High | Low | **Rejected** — measures reading |
| Audio prompt + large visual choices | None | Low | **Viable** |
| Proctor-delivered, tablet-recorded | None | High (1:1 adult time) | Viable, costly |
| Physical manipulatives + observation | None | Very high | Not scalable |

**v0.55 correction — administration mode is NOT decided.**

v0.54 recommended self-administered audio. That was a Pragati design
hypothesis presented too confidently. The two candidates are compared
below, and the evidence needed to choose between them (PARAKH's
foundational-stage methodology, and India's Foundational Learning Study
approach) **has not been read**.

| Criterion | Administrator-led oral | Self-administered audio + visual |
| :--- | :--- | :--- |
| Construct validity | Higher — adult can confirm the child understood the task | Lower — a mis-tap or missed audio is indistinguishable from not knowing |
| Language | Adult can use the child's language naturally | Fixed recordings; every language needs separate production and DIF work |
| Device burden | One device per assessor | One device per child, headphones needed |
| Adult time | High — 1:1, the dominant cost | Low |
| Standardisation | Lower — depends on the assessor's delivery | Higher — identical stimulus every time |
| Scalability | Poor at national scale | Good |
| Young-child behaviour | Adult can re-engage a distracted child | Disengagement looks like incorrect responses |

**The trade-off is genuine: administrator-led buys validity with adult
time; self-administered buys scale with construct risk.** India's own
large-scale foundational surveys are, to our understanding,
administrator-led — which is evidence worth checking before choosing.

**Status: administration mode `provisional`. Not decided in v0.55.**

Item formats that would work: large picture select, counting a
displayed set, ten-frame recognition, number-line placement by tapping,
drag-and-drop grouping, shape matching. All exist as declared formats
in the item-type architecture; none has a scorer yet.

---

## 3. Construct validity concerns

1. **Audio is part of the construct delivery, not a decoration.** If
   audio fails or is poorly recorded, the item measures listening.
2. **Instruction language matters more, not less.** A six-year-old's
   home language is likelier to differ from the instruction language.
   Audio makes multi-language delivery easier but DIF risk higher.
3. **Tapping is a motor skill.** Touch targets must be large and
   forgiving; a mis-tap must not read as a wrong answer.
4. **Guessing is high with few options**, which argues for more options
   or more items — both of which fight the attention limit.

---

## 4. Practical constraints

- **Attention: 10–15 minutes**, not 40. This alone rules out the
  35-item design.
- **Device:** audio output required, headphones strongly preferred. In
  a shared classroom without headphones, audio delivery collapses.
- **Adult support** is required for setup and reassurance even when
  self-administered.
- **Adaptive routing is questionable at this age.** A young child who
  meets several too-hard items in succession may disengage in a way
  that a Class 8 student would not, and disengagement is
  indistinguishable from inability in the response data.

---

## 5. Is an interim/CAT model developmentally appropriate?

**Doubtful in its standard form.** Three windows a year of adaptive
testing for six-year-olds is a large imposition for a measurement whose
precision at that age is unproven. A shorter, less adaptive,
teacher-administered instrument is likelier to be both usable and
defensible.

---

## 6. Verdict

### FEASIBLE WITH A SEPARATE EARLY-PRIMARY FORM

Not feasible inside the main Pragati Growth design, because nearly
every parameter differs: length (10–15 min vs 40), delivery (audio vs
text), formats (visual/manipulative vs selected-response), routing
(fixed or lightly adaptive vs adaptive), and reporting (teacher
observation alongside responses).

Calling it "the same assessment for younger children" would be wrong.
It is a different instrument sharing a competency framework.

**Not recommended for v0.55.** The middle-stage instrument is not yet
validated, and building a second unvalidated instrument first would be
the wrong order. Revisit once the middle-stage pilot has field-test
data — the same evidence would inform the early-primary design.

---

## 7. What would change this verdict

- PARAKH's foundational-stage methodology, once read, may already
  answer the delivery questions.
- Evidence that audio-delivered numeracy items function well in Indian
  classrooms at scale.
- A partner school willing to trial administration burden realistically.
