# Learn / Practice Curriculum Completeness Plan — Classes 1–12

**A separate track from Growth validation.** Growth needs a defensible
measurement framework before items are written. Learn and Practice need
correct, complete teaching content. These block each other far less than
it might appear, and running them in parallel is deliberate.

**This plan does not author content.** It defines how completeness is
achieved and measured, and records the evidence gap as it stands.

---

## 1. What "complete" means for one chapter

A chapter is complete when all of the following exist and are recorded
against the four-axis readiness model:

| Element | Readiness axis |
| :--- | :--- |
| Official chapter record verified from primary source | Curriculum |
| Chapter mapped to Pragati modules and skills | Curriculum |
| Concept lessons for every mapped skill | Instruction |
| Worked examples | Instruction |
| Visual representations | Instruction |
| Misconception notes | Instruction |
| Guided practice items | Practice |
| Independent practice items | Practice |
| Mixed practice usable (≥2 skills with items) | Practice |
| Chapter check blueprint | Practice |
| Teacher resources and printables | Instruction |

Growth readiness is **not** on this list. A chapter can be fully
complete for Learn and Practice while remaining `not_eligible` for
Growth — that is the normal state and not a defect.

## 2. Current evidence gap

| Grade | Official chapter inventory | Verification | Pragati modules |
| :--- | :--- | :--- | :--- |
| 1–2 | **Not established** | None | Placeholder modules only |
| 3–5 | **Not established** | None | Placeholder modules only |
| 6 | 10 chapters (Ganita Prakash) | Secondary corroborated | 6 legacy modules, 3 unmappable |
| 7 | **Disputed** (15 vs 16 chapters) | Contradictory secondary | Legacy modules |
| 8 | **Not established** | None | Placeholder modules |
| 9 | Unit structure known from CBSE syllabus | **Primary source read** | Placeholder modules |
| 10 | Partially known (CBSE syllabus located) | Primary, partial | Placeholder modules |
| 11–12 | **Not established** | None | Placeholder modules |

**The honest headline: only Class 9 has a primary-source-verified unit
structure, and Pragati has no real content for it.** Class 6 has the
content and no verification. That inversion should drive sequencing.

---

## 3. Sequence

### Phase A — Establish official inventories (research, no authoring)

Per grade: locate the current official textbook and syllabus, record
exact chapter numbers and titles with citation, mark
`primary_source_verified`, then map to Pragati modules as exact /
partial / combined / split / unmapped.

Order: **6 → 7 → 9 → 10 → 8 → 5 → 4 → 3 → 11 → 12 → 2 → 1.**
Class 6 first because content already exists; Classes 9–10 next because
their syllabi are already reachable.

*Exit:* a grade's inventory is verified and mapped. No content written.

### Phase B — Close mapping gaps

Decide, per unmapped item:
- Official chapter with no Pragati module → author (Phase C).
- Pragati module with no official chapter → retire, remap, or keep as
  explicitly supplementary. **This is a curriculum decision, not an
  engineering one.** Three Class 6 modules are already waiting on it.

### Phase C — Author instruction, one chapter at a time

Lesson → worked examples → visuals → misconceptions → teacher notes.
Every chapter reviewed by a teacher before `instruction: reviewed`.

### Phase D — Author practice

Enough items that mixed practice genuinely samples ≥2 skills, plus a
chapter-check blueprint where the chapter warrants one.

### Phase E — Migrate to the content registry

Per `contentRegistry.ts`, chapter by chapter, so the bundle stops
growing linearly with the curriculum.

---

## 4. Gap matrix — how it is maintained

Derived from data, never hand-maintained: official chapter count,
verification status, mapped modules, unmapped official chapters,
obsolete Pragati modules, lesson/item counts, and the four readiness
axes. Surfaced in Admin & Research.

**A grade is never reported as "complete" from module count alone.** A
grade with ten placeholder modules and no verified inventory is 0%
complete, not 100%.

---

## 5. What this plan explicitly refuses

- Mass-authoring Classes 1–12 in one pass.
- Treating legacy module names as official chapters.
- Marking a grade verified from secondary sources.
- Blocking Learn/Practice work behind Growth validation.
- Blocking Growth validation behind Learn/Practice completeness.

---

## 6. Realistic sizing

12 grades × roughly 10–14 chapters ≈ **130–160 chapters**. Each needs
lessons, examples, visuals, misconceptions, and a practice bank, plus
teacher review.

**This is a multi-year content programme, not an iteration.** Any plan
implying otherwise is wrong, and stating so plainly is more useful than
an optimistic schedule.
