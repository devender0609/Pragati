# Learn / Practice Gap Audit — Representative Grades

Four grades audited from actual data, not from module names. Purpose:
stop Pragati drifting into a Growth-engine-only project.

**Method:** counts derived from the chapter resolver and inventory.
"Official units verified" means a primary source was inspected — the
answer is zero everywhere, and that is the headline.

## Class 2
Legacy starter modules only, no official inventory. Items exist but
lessons are generated from the item bank rather than authored. **Also
the stage where the current text-first UI is least appropriate** — see
the early-primary feasibility note.

## Class 4
As Class 2. No NCF-aligned source located for the preparatory stage.

## Class 6
The strongest grade, and still unverified. Ten Ganita Prakash chapters
are *identified* from secondary sources; none is primary-verified.
Fractions has hand-authored lessons, worked examples, visuals, and the
only chapter-check blueprint. Three legacy modules — decimals,
ratio_proportion, algebra — have **no standalone chapter in the current
textbook** and remain an open curriculum decision.

## Class 10
CBSE syllabus is reachable (`cbseacademic.nic.in` is fetchable), so
this grade is unusually easy to verify — but Pragati has only
placeholder modules and generated lessons for it. **Verification is
cheap here and content is absent; Class 6 is the inverse.**

---

## What this implies

1. **Verification and content are inversely distributed.** Class 6 has
   the content and no verification; Classes 9–10 have reachable sources
   and no content.
2. **Nothing is primary-verified anywhere.** Every "official chapter"
   in the product is a claim.
3. **Generated lessons are the norm.** Only Fractions is authored.

## Recommended next instructional phase

Class 6 first: verify the ten chapters from the textbook, resolve the
three unmapped modules, then author the seven Ganita Prakash chapters
Pragati lacks. It is the only grade where verification immediately
makes existing content legitimate.

**Do not start Classes 1–2** until the early-primary UI question is
settled — authoring text-first content for six-year-olds would need
redoing.
