# Instructional Pilot Recommendation

**Written:** 2026-08-24 (v0.61 §12)

## 1. Candidates

Only grades with an accessible primary source were considered. Three
qualify after v0.61's retrievals: **Class 6**, **Class 7**, **Class 8**.
Classes 1–5 and 9–12 have no primary-verified official unit list and are
therefore not eligible — piloting instruction against an unverified
curriculum is the failure mode this project exists to avoid.

## 2. Scoring

Scored 1–5, higher is better. Evidence is from this iteration's
inspections and the item-bank census.

| Criterion | Class 6 | Class 7 | Class 8 |
| :-- | --: | --: | --: |
| Primary source certainty | 5 | 5 | 5 |
| Section-level mapping already done | 5 | 1 | 1 |
| Existing Pragati content at that grade | 5 | 2 | 1 |
| Content quality of what exists | 3 | 2 | 1 |
| Age-stage UI readiness | 4 | 4 | 4 |
| Size of gap to close | 3 | 2 | 2 |
| Reviewer availability | 3 | 3 | 3 |
| Usefulness to schools | 4 | 4 | 4 |
| **Total** | **32** | **23** | **21** |

### Notes on the scores

- **Source certainty is tied at 5.** All three books were retrieved from
  ncert.nic.in and read this iteration. Class 6 has no advantage here.
- **Mapping (5 vs 1)** is the largest single gap and the honest reason
  Class 6 leads: 60 sections are already recorded with four independent
  statuses. Grades 7 and 8 have chapter titles and section headings
  extracted but no mapping model populated.
- **Existing content (5 vs 2 vs 1).** Class 6 has 304 items and 22
  authored lessons. Class 7 has 24 items across 6 modules. Class 8 has
  none.
- **Content quality is only 3 for Class 6** — the reference module
  covers 5 of 9 official sections and averages 16-word stems. This is
  deliberately not scored higher.

## 3. Recommendation

**Class 6.** Total 32 against 23 and 21.

The decision is not close, but it is worth being precise about *why*,
because "work already exists" is not by itself a good reason — it is how
sunk cost gets rationalised.

The real argument is that Class 6 is the only grade where the full
chain can be exercised end to end **in this iteration**: primary source
→ verified section → stage-correct competency → authored content →
mathematically validated visual → practice → reviewer preview. Section
7.4 demonstrates that chain today. Choosing Grade 7 or 8 would mean
repeating the mapping work before any instructional question could be
asked, and would prove nothing about the process that Class 6 has not
already proved.

## 4. The argument against, stated fairly

Class 6's content has the **most to unlearn**. Three of its six modules
belong at Grades 7–8, and the reference module has four uncovered
sections. Grade 8 would start clean.

That is a real consideration and it is why the recommendation is for a
**pilot**, not for mass authoring. If educator review of the Class 6
mapping goes badly — if the section mappings are judged wrong — the
correct response is to re-examine the method, not to move grades.

## 5. Scope of the pilot

Recommended: **Ganita Prakash Grade 6 Chapter 7 (Fractions), all nine
sections.** One chapter, completely, to the standard in
`PRAGATI_COMPLETE_UNIT_STANDARD.md` — including the four sections
Pragati currently lacks.

Not recommended: all ten Class 6 chapters. Volume before the standard
is proven is the error this iteration was written to prevent.
