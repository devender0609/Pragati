# BASELINE

### 1. What was the actual v0.74 test count?

### 2. Why did 1364/1367 differ?

The *report* was stale; the code was always 1367. The report was written when
the suite stood at 1364. Afterwards the in-app coverage panel was fixed — it
still read "Need review 89" while the corrected document said 65 — and **3
tests** were added to `v074Routes.dom.test.tsx`, taking that file from 11 to 14.
1364 + 3 = 1367. The number was corrected in the release summary and not in the
report file. **My error, not a code defect.**

### 3. Is the release baseline now internally consistent?

Yes. `V0.74_REPORT.md` carries a visible **erratum** rather than a silent edit,
and `v075Baseline.test.ts` reads the file and asserts the figure, so the next
stale number fails the suite instead of shipping.

# PRODUCT

### 4. What screens were materially redesigned?

**One structural change: the teacher desktop.** `TeacherWorkspace.tsx` replaces
the centred column at `lg+` with a persistent left rail carrying navigation and
`aria-current`, plus an optional context column. At 1440 Teacher was a ~768px
column with ~340px of dead slate on each side; it now uses the width.

`SURFACE`, `LAYOUT` and `READING` tokens were added — page/zone/panel/
interactive/feature/upcoming/attention, composition widths, and desktop
typography that steps up at `lg:` instead of stopping at `sm:`.

### 5. Does v0.75 look clearly different from v0.74?

**Only on teacher screens, and only at ≥1024px.** That is a narrow claim and
§33's threshold is not met. Do not describe this release as a visual
transformation.

### 6. Which screens still look prototype-quality?

Nearly all of them. **Teacher Assign is the worst** — it lives outside
`TeacherShell` entirely, so it does not even get the new rail, and still reads
"Assign assessments", "student-facing assessment cards", "stored on this device
only" above three cards showing 0. Classes, Assess, Insights and Resources have
the rail around them but unchanged content. Student Home, Class 6 Learn, the
Fractions journey and the lesson renderer are untouched.

### 7. What changed at desktop 1440?

Teacher only. Student desktop is unchanged.

### 8. Was Teacher fully redesigned?

**No.** §11 said this cannot slip again, and it partly did. The composition was
rebuilt; the content of five of six screens was not. The honest description is
"Teacher desktop layout", not "Teacher redesign".

### 9. Did Student lesson presentation materially improve?

**No.** §7–§9 were not attempted. Lessons are still long documents. The
`READING` tokens that would fix the tiny-text-at-1440 problem exist but nothing
consumes them yet.

# CONTENT

### 10. Are all 9 Fractions sections now complete drafts?

**Yes.** §7.9 "A Pinch of History" was one worked example and one independent
item short. Both were authored as **history reasoning, not arithmetic padding**:

- `s79.we2` walks how to evaluate the claim *"Indians invented fractions"* —
  separating the idea from the notation, and landing on a fairer sentence.
  Adding a fraction computation to satisfy a counter would have been the §7.9
  failure mode in miniature.
- `s79.i3` asks what the late arrival of the horizontal bar implies about
  notation generally.

**All three waivers are intact** — no visual, no interactive item, no
misconception — and a test asserts it.

# WHAT MUST NOT BE CLAIMED

- **v0.75 does not meet §33's visual threshold.** Teacher content still looks
  like v0.74; student lessons are still white documents; most pages are still
  white and grey. One composition primitive is not a redesign.
- **Nothing is reviewed or published.** Nine sections are *review-ready*, which
  means a package exists — not that anyone has read one.
- **§7.9's completion is unreviewed content** by the same maintainer as the rest.
  It closes a counting gap; it does not make the section good.
- **The 16-question instrument is untested on a real reviewer.** It may prove
  too short. That is discoverable only by sending it.
- **No Number Play content exists.**
- **Growth untouched**: no CAT, norms, calibration, secure items or mastery
  claims.
