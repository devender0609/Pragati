# Class 7 to Class 8 — interim transition audit

Written from the complete Class 7 decomposition and **all 7 Part I chapters of
Class 8**; Part II's 7 chapters are not yet read, so this audit is partial.
**[S]** source observation, **[P]** Pragati recommendation.

## Number and powers

**[S]** Class 7 reaches crores and decimal place value. Class 8 opens with
**squares, cubes and their roots** — the first inverse operations in the
programme after division — and then formalises repeated multiplication as
**exponent notation**.
**[S]** §2.3 **motivates zero and negative exponents by preserving the exponent
pattern** — the value is defined so that the division rule already established
keeps working, rather than being read off a count or a measurement. That is what
this section does; no claim is made here about how every earlier rule in the
programme was justified. The decomposed Classes 1-7 evidence already contains
deductive geometry, parity impossibility arguments and algebraic reasoning, so a
universal "first non-counting justification" claim would not be supportable.
**[P]** Author §2.3 with the consistency argument kept visible — the definition
is the point, not the result.

## Number systems

**[S]** Chapter 3 makes **representation itself the object of study** — tally
systems, Roman numerals, Egyptian, Mayan, Mesopotamian base-60 and Chinese rod
numerals — and then generalises place value to an arbitrary base. Class 7 uses
place value; Class 8 asks what it is and why it won.
**[P]** §3.4 is where the Classes 1-7 system finally gets named and explained.

## Geometry

**[S]** Class 7 proves the angle sum of a triangle and states the congruence
conditions. Class 8 **applies congruence as a working tool**: every quadrilateral
property — equal diagonals, bisecting diagonals, opposite angles, the rhombus
right angles, the isosceles trapezium — is proved by it rather than measured.
**[S] No prerequisite gap here**: chapter 4 rests directly on Class 7 Part II
chapter 1.

## Algebra

**[S] Identities are new.** Class 7 ends at equations solved systematically.
Class 8 extends the distributive property to products of expressions, names an
**identity** as a statement true for every value, and derives the square-of-a-sum
and difference-of-squares results — then uses them for mental computation.
**[S]** Chapter 5 completes a long arc: the divisibility tests Class 6 justified
informally are now **proved algebraically** from place value.

## Ratio and proportion — the genuine jump

**[S] Ratio is new at Class 8.** Nothing in the verified Classes 1-7
decomposition introduces ratio as a named object. Class 7 compares quantities,
scales recipes and converts units, but the ratio itself, its simplest form, the
rule of three and sharing in a given ratio all arrive in Part I chapter 7.
**[P] This is the Class 7→8 discontinuity to watch**, the counterpart of the
parallel-lines jump at Class 6→7. Chapter 7 cannot assume prior ratio fluency,
and Part II's Proportional Reasoning-2 will rest on it.
