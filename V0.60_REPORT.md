## 4. Grade fallback removed (§3)

The formal path no longer contains `?? 'class6'`. An unrecognised
classroom grade is refused with a message naming the fix. Assigning a
Class 6 form to a Class 9 class would have been silent and serious.

## 5. Supports now reach the assignment (§5)

`GrowthAssignmentDraft` carries `classWideSupportIds`, expanded per
roster student into `supportsByStudent`. v0.59 collected selections
into local state and emitted `accommodationsByStudentId: {}` — every
choice was discarded at the moment of assignment.

## 6. Exposure persisted with the correct context (§7, §8)

App loads the exposure log, records, and **saves** it. The runner passes
`'growth_field_test'`, not the generic `'growth'` — the precise
distinction v0.59 introduced the split fields for. Tested across two
students on the same item.

## 7. Frozen roster (§9, §10)

`assignedStudentIds` and `rosterFrozenAt` are captured at assignment
time and required — an assignment with no roster is refused. Eligibility
keys on the frozen roster, so a student added mid-window is **not**
silently handed a form assembled for a different cohort. Tested.

## 8. Honest response-quality metadata (§11)

Interruptions are measured **per item** and stored on the response. A
30-minute gap before item 2 is recorded on item 2, not item 1. v0.59
emitted zeros, which read as "no interruption occurred" — worse than
omitting the field.

## 9. Repository layer (§12, §13)

Assignment, session, exposure, and audit repositories with in-memory and
localStorage adapters. `STORAGE_MATURITY_NOTE` states plainly that
browser storage cannot be authenticated, centralised, auditable, or
cross-device, and it is surfaced in Admin. The session repository is
**assignment-aware**, so a stale session from a cancelled or expired
assignment cannot surface as "Continue".

Audit events cover the assignment and session lifecycle.
`auditEventIsSafe()` refuses any event containing item content — **a
test caught a real bug here**: the original guard matched `"stem"`, but
`JSON.stringify` escapes inner quotes, so serialised item content in a
detail string slipped through. Now matched on bare keys.

## 10. Assignment management and participation (§14, §15)

`AssignmentManagementPanel` shows each assignment's class, window,
dates, status, and per-student participation, with cancellation.

**Participation is built from the roster, not from sessions** —
deriving it from sessions would omit exactly the students who matter
most, the ones who have not started. It reports started / in progress /
finished / stopped early and **no performance data at all**, asserted
per row.

## 11. Field-test readiness dashboard (§16)

Admin now answers "what is blocking a pilot?" in one place: formal items
authored (**0**), specifications drafted vs reviewed (**8 / 0**), pilot
authorization status (**Blocked**), the specific blockers, and the
storage-maturity note.
