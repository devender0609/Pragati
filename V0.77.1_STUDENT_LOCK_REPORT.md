## §19 the fourteen questions

**1. Was "Take the Mixed assessment" removed or reclassified?** Audited
first. Both hero buttons called `onStartAssessment`; `mixed` runs the
ordinary adaptive item picker across skills — the same runner the
Practice tab uses. It is practice. Calling it an assessment made a
lesson page look like a test page and borrowed vocabulary from Pragati
Growth, which is a governed instrument and is not this. The button is
**gone from the student hero**; teachers still see it, in the technical
wording, because they are choosing what to assign.

**2. Where does mixed practice live now?** The Practice tab, which is
where a student goes for a set spanning skills. Nothing was removed
without a route: Home → Practice → Start a set reaches the same runner.

**3. Teacher/parent notes gone from Student?** Yes. v0.76 folded them
into an accordion, which made them quieter without making them
appropriate — a Class 6 student should not find guidance written to the
adult about them at the foot of their lesson. Content untouched, still
rendered for the teacher audience.

**4. Prototype disclaimer gone from Student?** Yes, and **the gate is
untouched**. The gate is `hasEligibleLearn`, which still holds all nine
official §7.x drafts out of the student product. Removing the sentence
publishes nothing. Teachers and reviewers still see it, because for them
it is the point.

**5. Final stage architecture.** Learn the idea · See it · Worked
examples · Try it · **Think deeper**.

**6. Where did Common mistakes go?** It lost its stage and kept all its
content. A misconception teaches when it is adjacent to the thing it
corrupts, not as a chapter of its own — and a dedicated stage made a
student read three ways to be wrong before being invited to be right
once. So: procedure misconceptions sit under the worked examples as
"Watch out for"; response misconceptions drive Try-it feedback, which
already selects the authored misconception matching the distractor
actually chosen; one concept misconception becomes the Think deeper
task. A test asserts all three authored mistakes still render.

**7. Is See-it Studio-quality?** Yes — fraction strip, number line,
large notation, the connector between them, and the same five choices
Home offers. **The fraction is read out of the authored visual spec**,
never chosen in the component: `{kind:'bars', bars:[{numerator:3,
denominator:5}]}` gives 3/5. Grids derive shaded-of-total. Anything else
falls back to the authored renderer, because inventing a strip for a
non-fractional visual would be a new mathematical claim. The renderer
got richer; the claim did not.

**8. Header spacing fixed?** Yes. Back was a grey link floating on paper
above the ink band, leaving a pale empty strip across every lesson at
1440. It now sits inside the field as the first element of the lesson.

**9. Internal ids absent?** Yes — asserted as *forbidden markers* on all
45 production captures: `FR.02`, `Reteach`, `diff.`, plus the three
seams above.

**10. Try-it, all 5 items?** Yes. Question → commit → feedback → next →
completion, with selection and feedback cleared on advance (asserted).
Diagnostic feedback only where the distractor's misconception code is a
real misconception; neutral corrective guidance otherwise, because
inferring a misconception from an answer that does not imply one is a
guess dressed as a diagnosis.

**11. §11 dark/light — the rule, decided not inherited.**
DARK wherever a mathematical object is demonstrated or manipulated at
working size: the lesson hero, See it, the Think deeper canvas. Dark is
what makes a drawn figure read as an instrument rather than an
illustration. LIGHT wherever the student reads for more than a sentence:
Learn the idea, worked examples and their misconceptions, practice
questions. The rule is about the activity on the surface, not about
which stage it is, so it holds for lessons that are not this one.
