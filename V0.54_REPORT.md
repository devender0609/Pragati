## 3. Corrections to v0.53 overstatements

**Computational Thinking is no longer described as settled.** Status is
now `provisional_design_recommendation`, with PARAKH review, expert
review, and dimensionality evidence listed as pending, and three
alternatives explicitly retained: a future CT indicator, a separate CT
instrument, or CT as a reported domain if evidence supports it.

**The "never" claim is corrected.** `CT_EVIDENCE_POSITION` now states
that selected-response items *can* carry partial CT evidence
(decomposition, pattern recognition); what a short form cannot support
is a reported CT *score*. Only the second is refused.

**Rational Number** separation is a `provisional_design_recommendation`
with "fold into Number Sense" retained as a live alternative.

**Cross-stage claim rewritten** to "strongest candidate … official
foundational and preparatory placement remains incomplete."

**Provenance levels introduced** — `directly_inspected_primary`,
`official_derivative`, `secondary_corroboration`,
`mathematical_inference`, `expert_judgement`. The v0.53 claim "NCF-SE
does not separate Rational Numbers" is now attributed to the CBSE
document that reproduces it. A test asserts no claim is overstated.

## 4. Early primary (Classes 1–2)

The v0.53 exclusion is removed. `docs/EARLY_PRIMARY_GROWTH_FEASIBILITY.md`
reconsiders it properly — v0.53 let a UI limitation decide an
assessment-population question, which was the wrong basis.

**Verdict: FEASIBLE WITH A SEPARATE EARLY-PRIMARY FORM.** Nearly every
parameter differs — length (10–15 min vs 40), delivery (audio vs text),
formats, routing, reporting. Calling it "the same assessment for
younger children" would be false. **Not recommended for v0.55**:
building a second unvalidated instrument before the first has field
data is the wrong order.

## 5. Blueprint domains vs reportable subscores (§8)

`reportableScales.ts` separates the two. A `BlueprintDomain` guarantees
coverage; a `ReportableSubscore` requires sufficient information,
precision, dimensionality, interpretability **and** a named approver.

`asReportableSubscore()` is the only path between them. A test asserts
that complete evidence *without* a named approver still yields
`observed_counts_only`, and that all six domains currently do.

---

## 6. Adjudication (§9/§10)

`reviewAdjudication.ts`. Two independent reviewers is stated as a
**Pragati internal governance standard, explicitly not an external
regulatory requirement**.

Disagreement now has a defined path: two reviews → disagreement
detected → adjudication by a third senior reviewer → recorded final
decision. **"Approve" and "approve_with_changes" are not treated as
agreement**, and an unresolved disagreement can never become approval —
`mayFreezeFramework()` blocks. Required perspectives: practising
educator and curriculum specialist; the assessment specialist advises
on measurability, not curriculum content.

`CURRENT_REVIEWS` is empty. Nothing has been reviewed.
