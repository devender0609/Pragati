## F/G. Semantic model — verdict B

`sampleSpace.ts` makes the experiment one object. S is authored; the event is
a subset; the favourable count, the complement, the probability and the
complement's probability are all derived. Changing an event changes its
complement in the same step, which a test demonstrates by narrowing one.

What earns B rather than A is a refusal. `probability()` **throws** when
`equallyLikely` is null, so the uneven spinner cannot be given a number at
all. A model that returned |E|/|S| regardless would make favourable-over-total
look universally valid, which is the single thing this chapter must not
teach. The assumption is carried as a justification string on the experiment,
in model language — "modelled as fair", never a claim about physical metal.

Deliberately not built: weighted outcomes, conditional probability, or any
distribution engine. A model able to express more would invite lessons that do.
