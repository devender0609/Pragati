# Classes 1–3 progression audit

Regenerated after Class 3 reached source completion, so this is no longer
provisional. **Source observation** and **Pragati recommendation** are kept
apart; nothing here changes the official curriculum.

Evidence behind it: Class 1 130 pages, Class 2 138, Class 3 208 — all read in
full text, with every picture-carried page rendered and looked at.

## First appearances, checked against the completed Classes 1–2 decomposition

| Idea | Precursor | Explicit introduction | Formal treatment |

So "Class 3 introduces these" is right for the explicit and formal treatment,
and the earlier precursors are real and worth building on. The Class 2 work is
not a lesser version of the Class 3 work; it is the concrete ground for it.

## Observations

- Where Class 3 revisits earlier ground it raises **range** (100 → 1000),
  **representation** (bundles → Dienes blocks), or **reasoning**
  (estimate-then-check, box diagrams). No unit was found that merely repeats.
- **No regression and no unexplained jump.** The steepest step is three-digit
  subtraction with exchange, and the book scaffolds it with blocks and a
  number line before any written procedure. This now rests on the complete
  visual evidence, not on a partial pass.
- Reasoning-extension material recurs in all three books (constraint grids,
  invariant tricks, deduction puzzles) and is consistently outside what the
  chapters teach.

## Pragati recommendations

- Author Class 3 number and operations after the Class 1–2 place-value and
  regrouping units, so the prerequisite chain is authored in order.
- Fractions and standard units have no Class 1–2 lesson to reuse; plan their
  representations from scratch.
- Decide the reasoning-extension question once, as a policy, rather than four
  times: 10 units across the three classes are waiting on it.
