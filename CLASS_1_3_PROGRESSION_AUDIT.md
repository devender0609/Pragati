# Classes 1–3 progression audit

Source observation first, Pragati recommendation second, and never the two
mixed. Nothing here changes the official curriculum.

## What the books actually do

| Strand | Class 1 | Class 2 | Class 3 |
|---|---|---|---|
| Number | counting to 100, tens and ones | to 999 through tens and ones, hundred as ten tens | to 1000, hundreds-tens-ones, comparison with > and <, word numerals |
| Addition / subtraction | within 20, strips and hops | two-digit with regrouping, fact families, error checking | three-digit with Dienes blocks, box diagrams, grid methods, estimation before calculating |
| Multiplication | equal groups, repeated addition | tables of 2, 3, 5, 10; arrays; commutativity noticed | tables built from skip counting and stick arrays, patterns and relations between tables |
| Division | — | sharing and grouping | sharing with a recorded repeated-subtraction column, remainders informally |
| Fractions | — | — | halves, quarters, three-quarters; half and double as inverses |
| Measurement | direct comparison, handspans | need for a standard unit, balance, capacity | the metre and litre and kilogram, with half and quarter of each |
| Geometry | long/round, rolls/slides | 2-D shapes, faces, edges, corners | square corners, properties of rectangle and square, decomposition, tiling, symmetry and mirror images |
| Data / time / money | picture counts, day parts, coins | pictographs, calendar, clock, paise | calendar arithmetic, minutes elapsed, notes and coins to `500 |

## Observations

- **Genuine extension, not repetition.** Where Class 3 revisits a Class 1-2
  topic it raises range (100 to 1000), representation (bundles to Dienes
  blocks), or reasoning (estimate-then-check, box diagrams).
- **Three ideas appear for the first time in Class 3**: fractions, standard
  units of length, capacity and mass, and division recorded as a procedure.
- **Prerequisite links run backwards cleanly**: Class 3 units cite Class 1-2
  unit ids where the earlier work is genuinely assumed.
- **No regression or unexplained jump** was found. The steepest step is
  three-digit subtraction with exchange, which the book scaffolds with blocks
  and a number line before any written procedure.

## Recommendations (Pragati's, not the source's)

- Author the Class 3 number and operations units after the Class 1-2 place
  value and regrouping units, so the prerequisite chain is authored in order.
- Fractions and standard units have no Class 1-2 precedent; they will need
  their own representation work rather than reuse.
