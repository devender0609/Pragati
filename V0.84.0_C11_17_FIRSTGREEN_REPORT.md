## D/E. Architecture

`limits.ts` builds on `RealFunctionContract` from checkpoint 81. There is no
second function implementation, and the secant slope is the Straight Lines
slope idea rather than a new one.

Five things the brief said must not collapse are kept apart:

- **`x → a` is not `x = a`** — `includesTarget: false` by construction
- **Value at a point is a separate field from the limit**, and the limit is
  never computed by evaluating at the target
- **Nonexistence is a named state** carrying a written reason, never NaN,
  Infinity or null
- **A two-sided limit needs both sides to agree** — disagreement is reported,
  not averaged
- **A hole survives cancelling** — the original stays undefined where the
  simplified expression is defined

The model decides at offsets down to 1e-8; the table a student reads shows
0.1, 0.01, 0.001. Sampling illustrates behaviour and never defines it.

## F/G/H. Rate of change, and existence against nonexistence

Secant slopes **4, 3, 2.5** close on a tangent slope of **2** at x = 1, and 6
at x = 3 — all derived, none typed. An interval of zero width is refused
rather than divided by.

Every existence test carries a nonexistence fixture, because a model that
always returns a number has not represented a limit:

| Case | Result |
|---|---|
| `(x²−1)/(x−1)` at 1 | no value, **limit 2** |
| signum at 0 | value 0, **limit does not exist** |
| `1/(x−1)` at 1 | no value, **no limit** — grows without bound |
| `x²` at 2 | value and limit both 4 |

## I/J. Polynomials, rationals and the hole

Direct substitution is allowed only inside the domain. The cancelling case is
represented explicitly: the simplified expression must agree away from the
hole **and** the original must remain undefined at it, or the case is
rejected. A claimed cancelling case that fails either is refused.

## K. Transcendental limits

`sin x / x → 1`, `(eˣ−1)/x → 1`, `log(1+x)/x → 1`, each with no value at 0.
A test reads the same quotient as a **degree** measure and asserts it does
**not** approach 1 — the angle unit is part of the mathematics.
