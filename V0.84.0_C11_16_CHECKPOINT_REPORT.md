## C. Worst bottom-clearance gap

**124px against an 8px minimum**, measured at scroll end with a real wheel
event on the lowest visible control.

A first pass counted **16 overlaps at 360px**. Every one was
control-against-nav, none control-against-control. That is the checkpoint-84B
false positive: the bottom bar is fixed, so at an arbitrary scroll position a
mid-document control legitimately passes beneath it and the reader scrolls
on. The harness now reports the two separately, because only
control-against-control is a layout defect and only end-of-scroll clearance
answers whether the last control can be reached.

**Classification: harness, not product.** No layout was changed.
