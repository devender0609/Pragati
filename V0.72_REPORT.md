# B. Content completeness

## 5–6. What does "enough content" mean, and how does Chapter 7 measure?

`instructionalCompleteness.ts` defines a **complete instructional draft**: at
least 3 explanation paragraphs, 2 worked examples, 2 guided items, 3 independent
items, plus — *where applicable* — a visual, an interactive item, a reasoning
task and a documented misconception, with answer rationales, teacher notes and
alt text throughout.

**Class 6 Chapter 7: 8 of 9 are complete instructional drafts. 0 reviewed. 0 published.**

§7.9 is the one incomplete draft, and the report names the gap rather than
aggregating it: *1 worked example (needs 2); 2 independent items (needs 3)*.

### Applicability is part of the model, deliberately

A naive checklist fails §7.9 for having no diagram and no interactive item — and
the "fix" would be **bolting a quiz about dates onto a discussion section**,
making the content worse to turn a number green.

Every requirement can be waived, and a waiver must carry a reason a reviewer can
reject. §7.9's three are recorded in full beside the requirements it does
satisfy.

### §25 — a skeleton never reads as a draft

A test constructs a one-paragraph, zero-worked-example section from a real one
and asserts it classifies as `generated_skeleton`, not
`complete_instructional_draft`. The thresholds are set where a generated
skeleton fails them.

### A model bug found and fixed

The first run reported **§7.4 — the most thoroughly audited section in the
chapter — as missing misconception support.** Its four misconceptions live in
the *frozen §7.4 map*, not the chapter registry, so counting only the registry
produced a false gap. The model was wrong, not the content.

## 7. Is the backlog complete?

**89 official records** with no complete, reviewed content: Class 6 (65), Class 9
(6), Class 10 (7), Class 11 (5), Class 12 (6). 80 need Learn, 80 need practice,
**89 need review**.

**Derived, not maintained.** A hand-kept backlog forgets by omission — a record
left out of an edit never appears, and nobody notices because the list is the
only thing anyone checks. A test asserts the entry count equals the registry's
own record count for verified classes, so the moment a pending class becomes
verified, all of its records appear.

Classes 1–5, 7 and 8 produce **no entries** — not because they are complete, but
because their structure is unread. Inventing entries for them would be the same
error as inventing a chapter count.

# C. Product truthfulness

## 8–9. Are the two contradictions fixed?

**Yes, both, and by the same fix.**

| Screen | v0.71 said | The problem |
|---|---|---|
| Fractions landing | *"START NEXT · 7.2 Fractional Units as Parts of a Whole"* | §7.2's own row, six lines below, said **Coming soon** |
| Progress | *"Start: 7.2 Fractional Units as Parts of a Whole"* above *"0 parts started"* | Named an official section whose lesson is unpublished |

Both were **true of what would open** — legacy related practice — and **false
about what the label promised**. A student tapping "7.2 Fractional Units as
Parts of a Whole" expects §7.2 of their textbook.

**§15 — one canonical selector.** `nextActionForChapter()` returns the *kind*
explicitly, and `officialSectionId` is **null** for legacy practice even though
the route is reached through a section id — carrying it is exactly how a legacy
activity came to wear an official section title on two screens. The
student-facing label is computed there, so no screen writes its own.

Both now read: **"Fractions as parts of a whole — Related practice, not a
chapter lesson"**. Tests assert the label never starts with a section number,
never contains a skill code, and `mayUseOfficialSectionLabel()` returns false.

## 10. Can a teacher see the gap?

Yes. The teacher table gained a **Complete drafts** column and a panel stating
the distinction plainly:

> Classes 9–12 have a fully verified official curriculum and no Pragati teaching
> content at all. Every official unit is listed for students; none of it can be
> opened yet. That is a gap in what Pragati has built, not in the curriculum.

## 11. Can an administrator see all three truths at once?

Yes — the Admin matrix renders them as three separate column groups, plus the
derived backlog. The headline states omissions explicitly and turns red if any
verified class is missing a record.

  centred mobile. Only the Teacher Overview was ever redesigned.

- **Nothing is student-ready.** 0 educator-reviewed, 0 published. "Complete
  instructional draft" means every applicable component exists; it says nothing
  about whether the teaching is good.
- **Seven classes have an unknown official structure**, and the gate cannot
  check a source nobody has read.
- **Classes 9–12 have a verified curriculum and no content whatsoever.**
- **89 backlog records** is a description of the gap, not a plan to fill it.
- **Growth untouched**: no changes to CAT, scoring, norms, secure items,
  calibration or mastery claims.
