## P. Section extents — upgraded, and c12.07 corrected
Every section is now anchored by (PDF page, body line) at both ends. The
start is the heading line. The end is the line before the next heading, or,
for a chapter's last section, the line before the Miscellaneous Exercise (or
Summary in Chapter 12).

survives re-runs (a builder bug that dropped it on a second run was caught
