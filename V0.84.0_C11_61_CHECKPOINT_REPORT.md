## Version locking

Each packet carries a **fingerprint over instructional content only** —
goal, explanation, vocabulary, examples, practice, reasoning, summary,
visuals. Metadata churn leaves it unchanged; a wording change does not.

A reviewer copies that fingerprint into their response. If the lesson is
edited afterwards, the fingerprint no longer matches and the review cannot
silently be treated as current.

## No pre-filled judgement

Every reviewer field is `null`. Packets state **"Automated structural
checks passed… they say nothing about whether it teaches the objectives"**
— never "pre-reviewed" or "aligned". A test asserts that wording, because
the one thing that would wreck this wave is a reviewer reading my
conclusion instead of forming theirs.

Unit results are required per unit and never collapsed: §7.2 can come back
REVISE overall with three units ALIGNED and one MISALIGNED.
